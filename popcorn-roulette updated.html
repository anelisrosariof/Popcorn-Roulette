One-time setup

This page gets its movies from TMDB, a free movie database. It needs your own free access key:

  1. Create a free account at themoviedb.org and verify your email.
  2. Go to Settings → API and request a key. Choose Developer, personal/non-commercial use.
  3. Copy the long API Read Access Token (the short API Key works too) and paste it here.

Your key is saved only in this browser on this device.
