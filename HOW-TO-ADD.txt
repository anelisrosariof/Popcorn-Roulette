Put scrapbook.css and scrapbook.js in the same folder as Popcorn-Roulette's index.html.

Then add these two lines to index.html:

1) Right before </head>:
   <link rel="stylesheet" href="scrapbook.css">

2) Right before </body> (after the existing <script>):
   <script src="scrapbook.js"></script>

Nothing else changes: the picker logic, ids and TMDB code are untouched.
To go back to the old look, delete those two lines.
